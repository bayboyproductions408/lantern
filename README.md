# Lantern

A free Bible reading and listening app.

Lantern reads scripture aloud in English (King James Version) and Spanish (Reina-Valera 1909). Both translations are public domain.

It includes reading plans, full-text search across all 62,202 verses, bookmarks and a sleep timer. There is no subscription, no paywall and no account required. Running costs are covered by advertising and voluntary donations.
